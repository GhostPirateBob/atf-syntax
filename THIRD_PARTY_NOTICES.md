## ATF language data

Function and field names, signatures and short behaviour descriptions describe the ATF formatting language as implemented by WACUP and Winamp 5, for interoperability. The descriptions are written for this extension. A few one-line usage examples (e.g. `$mod(21,8)` → `5`, `$repeat(*,%rating%)`) match the examples in the public WACUP/Winamp ATF help and changelogs. No WACUP or Winamp code is included; the parser is an independent TypeScript implementation written to reproduce WACUP's observable behaviour.
